# 最终演示：按顺序亲自操作一次

这份演示约需 5–10 分钟。演示步骤已由开发版和构建版实际回放；你是否已经亲自完成，需要由你自己确认。输出文件为 `/tmp/svg-editor-demo.svg`，重复演示会覆盖这份临时结果，不改老师的 SVG 样例。

## 1. 启动

在终端执行：

```bash
cd /Users/tanshixin/code/mlcourse/svg-editor
npm run cli
```

看到 `svg>` 后，下面的命令都输入到编辑器中。只复制命令，不复制 `svg>`。

## 2. 创建两个节点和一条线

```text
init 800 600
create g flowchart
create g node1 in flowchart
create rect start 120 100 160 60 #4a90d9 in node1
create text start-label 155 135 "开始" in node1
create g node2 in flowchart
create rect process 520 100 160 60 #f5a623 in node2
create text process-label 545 135 "处理数据" in node2
create line arrow1 280 130 520 130 black in flowchart
tree
```

检查：`flowchart` 下有 `node1/node2/arrow1`；两个节点各含一个矩形和一段文字。共 8 个图形元素，包含组，不计根 svg。

## 3. 移动整个节点，再撤销和重做

```text
move node2 0 100
show process
show process-label
undo
redo
undo
```

移动后，矩形的 `y` 是 200，文字的 `y` 是 235，二者一起下移。第一次 `undo` 后恢复 100/135，`redo` 后再次变成 200/235；最后一次 `undo` 恢复原位。

可以解释：组和叶子共享图形接口，组递归操作孩子；一条 move 是一个 Command，因此撤销一次就恢复整个节点。

## 4. 修改文字，检查 redo 被清空

```text
set process-label text "处理数据 v2"
redo
```

文字更新成功。随后应看到 `error: nothing to redo`：新的编辑清除了原先可重做的移动。这是预期结果。

## 5. 保存并用浏览器查看

```text
save /tmp/svg-editor-demo.svg
undo
```

应看到保存成功，计数为 8；随后是 `error: undo not allowed after io command`。保存成功建立历史屏障，不能退回保存前的编辑。

另开一个终端执行：

```bash
open /tmp/svg-editor-demo.svg
```

检查：蓝色“开始”节点、橙色“处理数据 v2”节点、黑色连接线能正常显示。

## 6. 读回后继续编辑

回到仍在运行的编辑器：

```text
read /tmp/svg-editor-demo.svg
show process-label
move node2 0 100
undo
save
```

检查文字仍为“处理数据 v2”，父级仍是 `g#node2`，坐标为 545/135。读回后第一次成功编辑解除屏障，可以撤销这次移动；无参数 `save` 保存到刚刚 read 的路径。

## 7. 检查缺失 id 的补全

```text
read examples/other.svg
show rect1
undo
```

应看到 `warning: assigned id rect1 to unnamed <rect>`，随后读入 7 个元素。`rect1` 是 400×300 的白色背景矩形。最后一次 undo 再次被文件屏障拒绝。

按 Ctrl+D 退出编辑器。若结果不一致，把执行的命令和输出告诉我，不要先改代码或移动 `final` 标签。

## 8. 准备解释与交作业

你应能用自己的话解释：Command 管理一次编辑与恢复，Composite 让组和叶子统一操作，XML/文件模块把读写与图形规则隔开。

课程平台上传项目根目录的 `README.md`，其中包含公开仓库及最终标签链接；`doc/README.md` 留在仓库中。上传后确认平台显示提交成功。亲自演示和课程平台上传无法用自动测试代替。

只想完整回放时，可退出编辑器后执行：

```bash
npm run cli < examples/final-demo.txt
```

应有三条预期 error（一次 nothing to redo，两次历史屏障）和一条补 id 警告；自动回放不代表你已经亲自完成了逐步演示。
